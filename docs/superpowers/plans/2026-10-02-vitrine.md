# Vitrine (visitas e conversão) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tela `/vitrine` com o pulso da conta (visitas, conversão, venda por visita, gráfico semanal, frases) e a lista "Onde agir" (anúncios que pedem ação), sobre dados já coletados pelo ADR-0172.

**Architecture:** 1 RPC SQL só-leitura `vitrine_resumo(p_inicio, p_fim)` agrega visitas × pedidos por MLB, semana e dia da semana (período + anterior de mesmo tamanho). Toda regra calibrável (KPIs, cobertura, rótulos, pedidos em jogo, frases) vive em `src/lib/vitrine.ts`, funções puras testadas com vitest. A página só busca e desenha.

**Tech Stack:** Postgres (Supabase), React + TS + Vite, shadcn/ui, recharts `ComposedChart`, vitest.

**Spec:** `docs/decisions/0176-vitrine-visitas-conversao.md` + glossário (`docs/reference/glossario.md`: Vitrine, Conversão, Onde agir, Estado do dia).

## Global Constraints

- Conversão = pedidos faturáveis ÷ visitas, %; faturável = status `paid`, `partially_refunded`, `refunded` (espelho de `STATUS_FATURAVEL` em `supabase/functions/_shared/platform-admin/sales-summary.ts:14`).
- Pedido conta por order (`ml_vendas.id`), não pack; dia da venda = `date_closed` em BRT (`America/Sao_Paulo`), mesmo corte do Dossiê (`src/lib/sku-trafego.ts:142`).
- Só pares MLB × dia com `estado = 'ok'` entram; pedidos contam **nos mesmos pares**.
- Período termina em hoje BRT − 2 dias. Presets: 4 sem (28 d), 12 sem (84 d), 6 meses (182 d). Período anterior = mesmo número de dias imediatamente antes.
- Cobertura < 95% → aviso; < 80% → KPI vazio (`null`, nunca 0).
- Limites iniciais de "Onde agir": 100 visitas, 0,5× média, 5 pedidos, 1,5× média, queda 30%, 7 dias — em constante `LIMITES`, calibrados na Task 6.
- Frases determinísticas, sem IA, máx. 3, trava: ≥ 30 pedidos por grupo e |z| ≥ 1,96; dia da semana só com ≥ 12 semanas.
- Fora: mapa de calor, tabela por dia da semana, tarifa por visita, presets "1 ano"/"Tudo".
- Migration só via `supabase migration new` + `supabase db push`; validar com `npm run db:check`. RLS/escopo por `current_org_id()`.
- Modelo: Task 1 (migration) em **opus**; demais em **sonnet**. Revisão de diff por task e pré-merge: Grok 4.7 xhigh via `cursor-agent`.
- Copy da UI em pt-BR. Nome da tela: **Vitrine**; subtítulo "Quem vê seus anúncios e quem compra."

## Review Focus

1. **Org nova ou sem coleta** (0 linhas em `ml_item_visitas_dia`): tela mostra estado vazio explicando que a coleta de visitas leva até 1 dia, sem erro nem "0%". → teste em Task 2 (`kpisVitrine([])`) e Task 5 (estado vazio).
2. **Período anterior fora dos 150 dias coletados** (6 meses × 2 = 364 d): anterior tem cobertura baixa → Δ fica oculto, não "+∞%". → teste em Task 2 (`delta` com anterior `null`).
3. **Anúncio criado no meio do período** (poucas linhas): não pode virar "Perdendo visitas" nem "Invisível" por falta de dado. → testes em Task 3 (cobertura por item < 80% e `dias_ok_ult7 < 7`).
4. **Venda sem visita medida no dia** (dia `pendente`/`falha`): pedido não pode inflar conversão. → teste SQL em Task 1.
5. **Usuário de outra org**: RPC nunca vaza linhas de outra org. → teste SQL em Task 1.

```sql
create or replace function public.vitrine_resumo(p_inicio date, p_fim date)
returns jsonb
language sql stable security definer
set search_path = ''
as $$
  with org as (select public.current_org_id() as id),
  j as (
    select p_inicio as ini, p_fim as fim,
           p_inicio - (p_fim - p_inicio + 1) as ant_ini
  ),
  vis as (
    select v.ml_item_id, v.dia, v.visitas, v.estado
    from public.ml_item_visitas_dia v cross join org cross join j
    where v.org_id = org.id and v.dia between j.ant_ini and j.fim
  ),
  ped as (
    select i.ml_item_id,
           (s.date_closed at time zone 'America/Sao_Paulo')::date as dia,
           count(distinct s.id) as pedidos,
           sum(i.quantity * i.unit_price) as receita
    from public.ml_vendas s
    join public.ml_vendas_itens i on i.venda_id = s.id
    cross join org cross join j
    where s.org_id = org.id
      and s.status in ('paid', 'partially_refunded', 'refunded')
      and s.date_closed >= (j.ant_ini::timestamp at time zone 'America/Sao_Paulo')
      and s.date_closed <  ((j.fim + 1)::timestamp at time zone 'America/Sao_Paulo')
    group by 1, 2
  ),
  base as (
    select vis.ml_item_id, vis.dia, vis.estado,
           coalesce(vis.visitas, 0) as visitas,
           case when vis.estado = 'ok' then coalesce(ped.pedidos, 0) else 0 end as pedidos,
           case when vis.estado = 'ok' then coalesce(ped.receita, 0) else 0 end as receita,
           vis.dia >= j.ini as atual,
           vis.dia > j.fim - 7 as ult7
    from vis cross join j
    left join ped on ped.ml_item_id = vis.ml_item_id and ped.dia = vis.dia
  ),
  agg as (
    select ml_item_id,
      coalesce(sum(visitas)  filter (where atual and estado = 'ok'), 0) as visitas,
      coalesce(sum(pedidos)  filter (where atual), 0)                   as pedidos,
      coalesce(sum(receita)  filter (where atual), 0)                   as receita,
      count(*) filter (where atual and estado = 'ok')                   as pares_ok,
      count(*) filter (where atual)                                     as pares_total,
      coalesce(sum(visitas)  filter (where not atual and estado = 'ok'), 0) as visitas_ant,
      coalesce(sum(pedidos)  filter (where not atual), 0)               as pedidos_ant,
      coalesce(sum(receita)  filter (where not atual), 0)               as receita_ant,
      count(*) filter (where not atual and estado = 'ok')               as pares_ok_ant,
      count(*) filter (where not atual)                                 as pares_total_ant,
      coalesce(sum(visitas)  filter (where ult7 and estado = 'ok'), 0)  as visitas_ult7,
      count(*) filter (where ult7 and estado = 'ok')                    as dias_ok_ult7
    from base group by ml_item_id
  ),
  info as (
    select distinct on (ae.item_externo_id)
           ae.item_externo_id as ml_item_id, ae.titulo, ae.codigo_pai
    from public.anuncios_externos ae cross join org
    where ae.org_id = org.id and ae.item_externo_id is not null
    order by ae.item_externo_id, ae.criado_em desc
  ),
  titulo_venda as (
    select i.ml_item_id, max(i.titulo) as titulo
    from public.ml_vendas_itens i cross join org
    where i.org_id = org.id and i.ml_item_id in (select ml_item_id from agg)
    group by 1
  ),
  ads as (
    select distinct gi.ml_item_id
    from public.ml_ads_grupo_item gi
    join public.ml_ads_grupo g on g.org_id = gi.org_id and g.ad_group_id = gi.ad_group_id
    cross join org
    where gi.org_id = org.id and g.status = 'active'
  )
  select jsonb_build_object(
    'inicio', (select ini from j),
    'fim',    (select fim from j),
    'itens', coalesce((
      select jsonb_agg(jsonb_build_object(
        'ml_item_id', a.ml_item_id,
        'titulo', coalesce(inf.titulo, tv.titulo),
        'codigo_pai', inf.codigo_pai,
        'status', t.status,
        'em_ads', ads.ml_item_id is not null,
        'visitas', a.visitas, 'pedidos', a.pedidos, 'receita', a.receita,
        'pares_ok', a.pares_ok, 'pares_total', a.pares_total,
        'visitas_ant', a.visitas_ant, 'pedidos_ant', a.pedidos_ant, 'receita_ant', a.receita_ant,
        'pares_ok_ant', a.pares_ok_ant, 'pares_total_ant', a.pares_total_ant,
        'visitas_ult7', a.visitas_ult7, 'dias_ok_ult7', a.dias_ok_ult7))
      from agg a
      cross join org
      left join info inf on inf.ml_item_id = a.ml_item_id
      left join titulo_venda tv on tv.ml_item_id = a.ml_item_id
      left join public.ml_trafego_item t on t.org_id = org.id and t.ml_item_id = a.ml_item_id
      left join ads on ads.ml_item_id = a.ml_item_id), '[]'::jsonb),
    'semanas', coalesce((
      select jsonb_agg(jsonb_build_object('semana', s.semana, 'visitas', s.visitas,
                                          'pedidos', s.pedidos, 'receita', s.receita) order by s.semana)
      from (select date_trunc('week', dia)::date as semana,
                   sum(visitas) as visitas, sum(pedidos) as pedidos, sum(receita) as receita
            from base where atual and estado = 'ok' group by 1) s), '[]'::jsonb),
    'dias_semana', coalesce((
      select jsonb_agg(jsonb_build_object('dow', d.dow, 'visitas', d.visitas,
                                          'pedidos', d.pedidos, 'semanas', d.semanas) order by d.dow)
      from (select extract(isodow from dia)::int as dow,
                   sum(visitas) as visitas, sum(pedidos) as pedidos,
                   count(distinct dia) as semanas
            from base where atual and estado = 'ok' group by 1) d), '[]'::jsonb)
  );
$$;

revoke all on function public.vitrine_resumo(date, date) from public, anon;
grant execute on function public.vitrine_resumo(date, date) to authenticated;

-- Menu novo (ADR-0047): quem já vê Faturamento passa a ver Vitrine.
update public.profiles set allowed_menus = array_append(allowed_menus, 'vitrine')
  where 'faturamento' = any(allowed_menus) and not ('vitrine' = any(allowed_menus));
```

```ts
import { diaBRT } from '@/lib/calendario-brt';

// (tipos exatamente como no bloco Interfaces acima)

const DIAS: Record<Preset, number> = { '4s': 28, '12s': 84, '6m': 182 };
export const COBERTURA_AVISO = 0.95;
export const COBERTURA_MINIMA = 0.8;

const somaDias = (iso: string, n: number): string =>
  new Date(Date.parse(`${iso}T00:00:00Z`) + n * 86_400_000).toISOString().slice(0, 10);

export function periodoVitrine(preset: Preset, agoraMs: number) {
  const fim = somaDias(diaBRT(agoraMs), -2); // ML fecha visitas em 48 h (ADR-0176 D-4)
  return { inicio: somaDias(fim, -(DIAS[preset] - 1)), fim };
}

export const taxa = (pedidos: number, visitas: number): number | null => (visitas > 0 ? pedidos / visitas : null);

function recorte(visitas: number, pedidos: number, receita: number, ok: number, total: number): Recorte {
  const cobertura = total > 0 ? ok / total : 0;
  const valido = cobertura >= COBERTURA_MINIMA;
  return {
    visitas, pedidos, receita, cobertura,
    conversao: valido ? taxa(pedidos, visitas) : null,
    vendaPorVisita: valido && visitas > 0 ? receita / visitas : null,
    avisoCobertura: total > 0 && cobertura < COBERTURA_AVISO,
  };
}

export function kpisVitrine(itens: ItemVitrine[]): KpisVitrine {
  const s = (f: (i: ItemVitrine) => number) => itens.reduce((acc, i) => acc + f(i), 0);
  return {
    atual: recorte(s((i) => i.visitas), s((i) => i.pedidos), s((i) => i.receita), s((i) => i.pares_ok), s((i) => i.pares_total)),
    anterior: recorte(s((i) => i.visitas_ant), s((i) => i.pedidos_ant), s((i) => i.receita_ant), s((i) => i.pares_ok_ant), s((i) => i.pares_total_ant)),
  };
}

export const delta = (atual: number | null, anterior: number | null): number | null =>
  atual == null || anterior == null || anterior === 0 ? null : (atual - anterior) / anterior;
```
Δ na UI: `delta(k.atual.visitas, k.anterior.conversao == null ? null : k.anterior.visitas)` — Δ de qualquer KPI some quando o anterior não tem cobertura mínima (Review Focus 2).

```ts
// ponytail: limites iniciais (ADR-0176 D-6), calibrados contra a Avil na Task 6.
export const LIMITES = { /* valores do bloco Interfaces */ } as const;

const mediana = (xs: number[]): number => {
  if (!xs.length) return 0;
  const s = [...xs].sort((a, b) => a - b);
  const m = Math.floor(s.length / 2);
  return s.length % 2 ? s[m] : (s[m - 1] + s[m]) / 2;
};
const cobre = (ok: number, total: number) => total > 0 && ok / total >= LIMITES.coberturaItem;

export function ondeAgir(itens: ItemVitrine[], convMedia: number | null): ItemAcao[] {
  const ativos = itens.filter((i) => i.status === 'active');
  const med = mediana(ativos.filter((i) => cobre(i.pares_ok, i.pares_total)).map((i) => i.visitas));
  const out: ItemAcao[] = [];
  for (const i of ativos) {
    if (i.dias_ok_ult7 >= LIMITES.diasInvisivel && i.visitas_ult7 === 0) {
      out.push({ item: i, rotulo: 'invisivel', emJogo: i.pedidos_ant });
      continue;
    }
    if (convMedia == null || !cobre(i.pares_ok, i.pares_total)) continue;
    const conv = taxa(i.pedidos, i.visitas) ?? 0;
    const cands: ItemAcao[] = [];
    if (i.visitas >= LIMITES.minVisitasSemVenda && conv < LIMITES.fatorSemVenda * convMedia)
      cands.push({ item: i, rotulo: 'sem_venda', emJogo: i.visitas * (convMedia - conv) });
    if (i.pedidos >= LIMITES.minPedidosConverte && conv >= LIMITES.fatorConverte * convMedia && i.visitas < med)
      cands.push({ item: i, rotulo: 'converte', emJogo: 0.5 * i.visitas * conv });
    if (cobre(i.pares_ok_ant, i.pares_total_ant) && i.visitas_ant >= LIMITES.minVisitasAntQueda
        && i.visitas < i.visitas_ant * (1 - LIMITES.quedaPerdendo))
      cands.push({ item: i, rotulo: 'perdendo', emJogo: (i.visitas_ant - i.visitas) * (taxa(i.pedidos_ant, i.visitas_ant) ?? 0) });
    if (cands.length) out.push(cands.reduce((a, b) => (b.emJogo > a.emJogo ? b : a)));
  }
  return out.sort((a, b) =>
    Number(b.rotulo === 'invisivel') - Number(a.rotulo === 'invisivel') || b.emJogo - a.emJogo);
}
```

```ts
const DOW = ['', 'Segunda', 'Terça', 'Quarta', 'Quinta', 'Sexta', 'Sábado', 'Domingo'];
const pct = (x: number) => `${(x * 100).toFixed(1).replace('.', ',')}%`;
const MIN_PEDIDOS = 30;
const Z = 1.96;

export function zProp(x1: number, n1: number, x2: number, n2: number): number {
  if (!n1 || !n2) return 0;
  const p = (x1 + x2) / (n1 + n2);
  const se = Math.sqrt(p * (1 - p) * (1 / n1 + 1 / n2));
  return se ? (x1 / n1 - x2 / n2) / se : 0;
}

export function frasesVitrine(r: ResumoVitrine, k: KpisVitrine, acoes: ItemAcao[]): string[] {
  const f: string[] = [];
  const { atual: a, anterior: b } = k;
  if (a.conversao != null && b.conversao != null && a.pedidos >= MIN_PEDIDOS && b.pedidos >= MIN_PEDIDOS
      && Math.abs(zProp(a.pedidos, a.visitas, b.pedidos, b.visitas)) >= Z)
    f.push(`Conversão ${a.conversao > b.conversao ? 'subiu' : 'caiu'} de ${pct(b.conversao)} para ${pct(a.conversao)} contra o período anterior.`);

  if (r.semanas.length >= 12 && r.dias_semana.length) {
    const melhor = r.dias_semana.reduce((x, y) => ((taxa(y.pedidos, y.visitas) ?? 0) > (taxa(x.pedidos, x.visitas) ?? 0) ? y : x));
    const resto = r.dias_semana.filter((d) => d.dow !== melhor.dow);
    const rv = resto.reduce((s, d) => s + d.visitas, 0);
    const rp = resto.reduce((s, d) => s + d.pedidos, 0);
    if (melhor.pedidos >= MIN_PEDIDOS && rp >= MIN_PEDIDOS && zProp(melhor.pedidos, melhor.visitas, rp, rv) >= Z)
      f.push(`${DOW[melhor.dow]} converte mais: ${pct(melhor.pedidos / melhor.visitas)} contra ${pct(rp / rv)} nos outros dias.`);
  }

  const n = acoes.filter((x) => x.rotulo === 'invisivel').length;
  if (n === 1) f.push('1 anúncio ativo está sem visita há 7 dias — veja abaixo.');
  else if (n > 1) f.push(`${n} anúncios ativos estão sem visita há 7 dias — veja abaixo.`);
  return f.slice(0, 3);
}
```
